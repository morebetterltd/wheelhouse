## Signal
Project: Basket Ledger, an invented shared grocery notebook.
Kind: report
Title: Bought-item marks disappear when I return
Text: I marked milk as bought in our shared grocery list. After closing the notebook and returning to it, the mark was gone. I bought milk again because I could no longer tell what we already had.

## Intent
Intent:
Make bought-item marks dependable when people return to their shared grocery list. People using Basket Ledger need to trust the list's record of what has already been bought, rather than lose that information and buy the same groceries again.
