# Five-features map

This hand-written reference maps the fixture's five baseline public features.
Shared setup is [the manual](../SKILL.md): a new owned process, loopback endpoint,
healthy doctor response and a caller-owned retained evidence directory. Counter
starts at zero. Drive through HTTP or the visible browser forms, not source
setters. Keep response bodies, headers and command statuses after cleanup.

## Features

- [Home](./home.md): navigation from the root page.
- [Health](./health.md): read-only health response.
- [Echo](./echo.md): form submission and text read-back.
- [Counter](./counter.md): increment and independent read-back.
- [About](./about.md): product identity and description.
